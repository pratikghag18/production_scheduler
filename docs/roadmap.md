# Roadmap — retired on 2 September 2026

This file was the project's living status document from 18 August to 2 September 2026. It has
been replaced by **`docs/plan.yaml`**, the single plan of record, and the page generated from it,
**`docs/plan.html`** (`npm run plan`). Everything this file carried now lives there: the stages
(as `stages`, with the roadmap's remaining checkboxes as `backlog`), the "Last updated" history
(as `sessions`, one entry per session), the NEXT list (as `next`), and the design plan's decisions
as a requirements ledger (`requirements`) that names what proves each one.

Nothing is to be added here. The previous content is in git history (`git log -- docs/roadmap.md`)
and every session it described is a `sessions` entry in the plan file.

The two hand-written gameplan pages that lived in `_delivery/` (`schedulerbuildout.html`,
`operator-training-matrix.html`) are retired the same way; `docs/plan.html` is their replacement
and is never edited by hand.
