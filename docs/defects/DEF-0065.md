## Expected

R-431: "Every button the bar offers and every readout it prints as done is decided by the same check the server runs ...

Cell 4 block to half) is something the server refuses; the bar should not offer it (Skip alone, or the plain refusal
before any yes). R-459: whatever it says is plain words, never a form or an id.

## Lead

**A suspicion, not a fact.** `precheckBeforeWrite` takes the probe's "overlap" to mean the caller can edit what it
overlaps, but the probe's readable rows only prove she can READ them; `apply_split_coverage` then needs
`app_can_edit_node` on every adjusted block's cell (the developer's F-249 reading, which this confirms). The fix is
the one CLAUDE.md section 4 names for DEF-0035: have the server say which overlapping blocks are editable (a field on
the probe's rows, or an `absence_recordable_people`-style set) and offer Split only when all are, Skip alone
otherwise. The uuid comes from `rewriteRefusal`'s `NO_EDIT_RIGHTS_REFUSAL` branch passing the server's
"You don't have permission to edit <node id>." text through as "You cannot change <id> from here." -- it wants the
cell's name from the board's own node list. No pin: the case needs a read-only grant fixture that the unit harness
does not have (`rewriteRefusal` is not exported either).
