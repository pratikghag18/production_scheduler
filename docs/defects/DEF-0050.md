## Reproduction

A tester lane ran `node scripts/voice/clips/score.mjs` for real against a fake Whisper server
answering POST `/inference` with chosen text, over synthetic 16 kHz mono WAVs and a manifest in
`record.mjs`'s shape, in a scratch folder: four listed clips, one missing, the last answered 500.
The tester read the code paths it names.

## Expected

R-453: "a change to the Whisper model, its decoding flags or the hint is accepted or rejected on
that table" -- the table and the results file are the product of a recording session.

## Actual

From the lane's run: clips 1 and 2 scored and printed, then the 500 threw out of `main()`
(`main().catch` prints the stack, exit code 1); no summary line, and no results JSON written. With a
missing clip the summary reads `mean WER 0.417 names 2/3 exact 1/3 wall/clip 7ms` and never says how
many of the listed clips were scored.

The code, read by the tester: `scoreOne` throws on any non-OK reply (`score.mjs` ~l.174-176), the
per-clip loop (~l.493-510) has no try around it, and the results are written once, after the loop
(~l.548). The fetch has no timeout or AbortSignal (`grep -n "AbortSignal\|timeout"` finds none in the
file), so a Whisper that stops answering stops the scorer with no message. Not re-run by the tester
against a failing server; the scorer's normal path was run by the tester on 12 of the maintainer's
real clips through the running small.en (`--from-trace 12`, read-only) and scored them sensibly
(`12 clip(s) scored across 10 entries, mean then-vs-now WER 0.000; mean wall 3978 ms per clip`).

## Lead

**A suspicion, not a fact.** Catch per clip and record the row as failed with its status; write
the results file incrementally or in a `finally`; give the fetch a timeout; print "N of M scored,
K missing, F failed" beside the mean.
