## Reproduction

Plant A's Cell 4 (Line 2) across one midnight: Housing A, Priya Shah, both
`[2026-10-12 03:00+00, 2026-10-12 11:00+00)` -- Sunday 11 Oct 22:00 to Monday 12 Oct 06:00 in

## Expected

R-407: "a block across one edge of the span is re-timed to the part outside" -- Priya keeps Sunday

## Lead

**A suspicion, not a fact.** `resolve.ts`'s clear of everyone builds per-block commands (~3763: a
block crossing one edge of the day becomes an end-edge move to midnight) and then, per run
overlapping the day, a `remove_run` (~3812-3871) that `delete_run` executes in `cascade` mode --
which deletes every assignment with that `run_id` regardless of time (the reviewer's comment at
~3819 says so, and handles the crew blocks outside the window by listing them, but not the blocks
the same lot trims). So a run that crosses the day's edge takes the trimmed block and its own
out-of-day part with it. The lot reported a state that was not
the state written. The typed walk (DEF-0042) runs this exact sentence first and would have shown
it on the current seed. A question for the maintainer rides on the fix: when Monday is cleared,
does Sunday's night crew keep Sunday 22:00-24:00, or does a night shift belong wholly to the day it
starts?
