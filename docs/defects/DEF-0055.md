## Reproduction

Tester's stack, demo seed (Maria Lopez has a block on Cell 2 tomorrow, 2 pm to 10 pm). Sign in as
**Ana**, open the bar, type **"clear Maria Lopez tomorrow"**. The same as the plant admin
(`dana@example.test`), and for "clear Sam Patel this week", "clear Tom Baker this week", "clear Lena
Novak tomorrow".

Pin: `npx vitest run src/test/defects/DEF-0055.test.ts`.

## Expected

R-430 (a standard): when a sentence names something the board cannot find, "the bar offers the
closest matches as buttons and asks which". The closest match to "Maria Lopez" is the person called
Maria Lopez. R-435 (a standard): "Two honest readings of a sentence become a question with both as
buttons, never a quiet pick." DEF-0043's third item expected a clear that names a person to answer
about that person.

## Actual

As Ana:

```
SAY  clear Maria Lopez tomorrow
No cell called "Maria Lopez" on your board. Did you mean one of these?
Cell 1
Cell 2
```

As the plant admin the same sentence offers Cell 1 to Cell 6. The trace shows the reading:

```
"heard":"clear Maria Lopez tomorrow", "read":"unassign \"everyone\" from Maria Lopez on tomorrow"
```

"remove Maria Lopez 2026-10-03" and "remove Tom Baker this week" read the person ("Tom Baker has no
block this week."). The pin:

```
× 'clear Maria Lopez tomorrow' is not answered 'No cell called "Maria Lopez"'
```

## Lead

**A suspicion, not a fact.** The grammar reads the words after "clear" as a place with the reserved
person "everyone" (R-407's clear of a place), and never as a person; "remove" takes a person. Before
session 194 this dead end had no buttons ("No cell called ... on this board."); DEF-0051's fallback
now offers the caller's own cells for ANY unknown cell name, which is right for "Cell 3" and wrong
for a name that is exactly a person on the board. The resolver has `ctx.operators`; when the place
text matches a person and no cell, it could read the person (as "remove" does) or ask "Did you mean
remove Maria Lopez tomorrow?" with that as the first button.

Seen in the same session and not filed, the same family as F-229 (a day word swallowed by the clause
before it): "extend Sam Patel today by 30 minutes" is answered `No person called "Sam Patel today"`,
and "extend everyone on Cell 2 2026-10-03 by 30 minutes" `No cell called "Cell 2 2026-10-03"`. Both
ask honestly and offer the right name, so nothing is written wrongly.
